# LOCAL GI ARENA — Settings / 设置

## Included offline planner / 随包的离线规划器

1. Extract the source archive and open planner.html in a browser. / 解压源码包，在浏览器打开 planner.html。
2. Use the built-in example first. To use your own catalog, import a compatible artifacts.json. / 可以直接用内置示例；要规划自己的套装，再导入格式兼容的目录数据。
3. Select the set, rarity and main stat for each of the five slots. Export JSON to save the plan. / 选择套装、星级和五个部位各自的主词条，导出 JSON 保存方案。
4. This worksheet does not connect to a database or grant items. / 导出的是规划表，不会向游戏背包写入物品。

## Combat environment / 战斗环境

The local edition targets Windows and version 7.1. Its intended setup uses a separate client folder, a local test account, and loopback-only services (127.0.0.1). Keep the live installation separate. These are deployment requirements, not settings automatically applied by this preview.

本地战斗版以 Windows 和 7.1 为目标，需独立客户端目录、本地测试账号和仅监听本机的服务。不要指向官服安装目录。本预览不会自动完成这些设置。即使另外准备客户端，也仍缺完整服务端、兼容资源和桌面控制器。

See the feature matrix and known limitations in the README before comparing damage. / 伤害对照前请先看首页的功能表和已知差异。
