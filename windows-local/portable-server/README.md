# Portable localhost server / 本地服务端首次配置
Prerequisites: Windows PowerShell 5.1 or later, JDK 21 (including **javac**), MongoDB 8 **mongod.exe**. Supply your verified 7.1 build as `server/grasscutter.jar` and install the compatible server data, Lua, webstatic, resource and plugin directories **in the extracted installation**. Do not import another user's server config, keys or database. These scripts alone do not supply game data.

以下命令在解压后的 windows-local 目录执行。不要把本目录覆盖到现有安装。首次配置只创建本地文件、编译本地辅助程序，不会打开网络、安装系统服务，也不会启动游戏。安装位置可以含空格或中文；不要使用分号、引号或百分号。已有账号数据不随工具一起分发。

1. Place exactly one JDK under `runtime/java` and one MongoDB distribution under `runtime/mongodb`; run `powershell -NoProfile -File portable-server/initialize.ps1`. Alternatively pass the absolute `-JavaPath` (java.exe) and `-MongodPath` (mongod.exe). The script resolves paths for this computer. Re-run after moving a stopped installation. A successful rerun preserves server config, account and database. Only use verified official runtimes.
2. Run `start-server.bat`; or invoke `powershell -NoProfile -File scripts/control.ps1 -Action start` for noninteractive startup. Endpoints: 127.0.0.1:8088 (HTTP), 22101 (game UDP), 27018 (database TCP). Another installation holding a port is left untouched. The application's local HTTP listener has TLS disabled; this configuration is not a network service for sharing.
3. When both listeners are ready, run `powershell -NoProfile -File portable-server/new-account.ps1 -Username arena -Uid 10013 -ShowPassword`. Use the displayed **local test** password, never an official account. The account is created on this installation, verified against its database, then bound to the controller. A conflicting username, UID or controller binding causes an error; nothing is reset. Repeat with the same arguments to recover the password under the same Windows user. Omit `-ShowPassword` to keep it off screen. Commands use only the local process. Never share the run directory, credentials, database, server config or logs. Password recovery storage is protected by Windows DPAPI and not portable to another Windows user.
4. Status: `status-server.bat`. Stop: `stop-server.bat`. Normal stop requests a save/shutdown and waits for the database. Do not back up while the database is live. The public repository is not a backup of your account. A server-only session keeps running until you stop it. If a separately verified isolated client is configured in `run/client-selection.json` as `{"executable":"<absolute executable path>"}`, the supervisor watches that exact process path, without modifying or launching it, and requests a clean shutdown approximately 30 seconds after its exit.
5. Diagnose startup problems in `logs/supervisor.err.log`, `server/logs/latest.log` and `logs/mongodb.log`. If the original game/server is running, stop your own instance normally before using this single-instance local setup. No extra firewall, proxy, hosts, root certificate or system service changes are needed for server setup. A failure to reach the clients' login or combat UI is not validated by server-only tests.
Optional preflight / 只读检查: powershell -NoProfile -File portable-server/test-initialization.ps1. Confirms local paths and settings only, not a successful client login.

**Runtime checks / 启停验收** (read-only):

    powershell -NoProfile -File portable-server/health.ps1 -RequirePlugins -Json
    powershell -NoProfile -File portable-server/health.ps1 -Stopped -Json

The first command checks this session's Java and MongoDB executable paths and creation times, ownership and loopback binding of HTTP/game/database listeners, game version via the HTTP status endpoint, a MongoDB driver ping, and current plugin readiness. The second checks that the supervised processes exited and the three ports are free. These checks do not prove an authenticated client entered the world or completed a combat action. Use -InstallRoot only with a trusted local installation; the ping uses that installation's Java helper.
