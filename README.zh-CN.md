# LOCAL GI ARENA
[English](README.md) · [搭建与启动](windows-local/distribution/README.md) · [验收记录](windows-local/distribution/ACCEPTANCE.md)

LOCAL GI ARENA 主要用于在 Windows 本地测试《原神》7.1 国服的**配队和队伍 DPS（每秒平均伤害）**。你可以用同一个木桩、相同的测试时长比较不同队伍的输出，也可以固定队伍和技能顺序，每次只换一项角色命座、武器精炼、圣遗物套装或主副词条，观察爆发伤害、整轮 DPS 和充能循环有什么变化。部分命座仍有已知问题，测试结果可能与官服不同。

**版本要求：** 请自行准备《原神》7.1 国服 Windows 客户端（7.1.0）。本仓库不包含游戏本体。

**客户端下载：** [夸克网盘：7.1.0 国服 Windows 基础客户端（含中文语音）](https://pan.quark.cn/s/c92a08de4fd5)。请下载全部四个 ZIP，分别解压到同一空目录，不要覆盖官服安装目录。资源包仅含客户端，解压后不会自动连接本地服务端。

**免责声明：** LOCAL GI ARENA 是非官方本地测试版，仅供学习交流，与米哈游及 HoYoverse 无隶属关系。游戏及素材权利归各自权利人所有；本项目的开源许可证不涵盖游戏客户端。部分命座仍有已知问题，请勿将测试数值视为官服结论。

**现在能用什么？** 想试圣遗物规划器，点 **Code → Download ZIP**，解压后打开 `planner.html`。它能规划五件套，不向背包发物品。要搭服务端，请看[Windows 组装指南](windows-local/distribution/README.md)：可以在新目录构建本机服务端、控制器和独立账号库。**仅有一个原版客户端，再下载源码 ZIP，还不是能直接玩的游戏包。** 面板可以识别客户端版本，不会修改或启动客户端。

| 模块 | 公开的内容 | 已验证的范围 |
|---|---|---|
| 角色、武器 | 桌面编辑器，按星级筛选，命座、精炼、增加同武器副本，本地账号绑定 | 编译、离线规则、界面操作及真实新账号的操作预演；没在新电脑进场发装备 |
| 圣遗物 | 单件／五件套编辑器、主副词条、配方；另有中英文网页规划器 | 控制器编译、规则与数值测试；网页工具不写账号 |
| 战斗服务端 | [33 个类的改动](windows-local/server-patches/)、[固定版本的构建配方](windows-local/build-server/)及[预编译工具组件](downloads/) | 全新目录实际运行服务端、加载两个插件；不等于逐角色伤害或实机木桩已验收 |
| 启停与账号 | 独立目录组装、运行库校验、首次账号、服务端启停、路径迁移 | 已实测本机登录接口、更名换目录重启、端口归属与停服释放 |
