# LOCAL GI ARENA
[English](README.md)

LOCAL GI ARENA 是面向 Windows 开发的本地《原神》战斗测试项目，固定在 7.1 版本。只支持战斗测试：保持队伍和目标不变，每次只换一项命座、武器或圣遗物，对照伤害、充能和增益。

## 现在就能试的部分
下载并解压源码 ZIP，在浏览器中打开 [planner.html](planner.html)（GitHub 文件页只显示源码），切换中文或 English，选择套装、星级及五个部位各自的主词条，然后导出 JSON。内置虚构示例，也支持手动导入兼容的本地 artifacts.json。只在浏览器中工作，不访问账号，不会把规划直接发进游戏。导入数据保留原语言。

## 功能清单

| 功能 | 本地 7.1 版 | 当前仓库草稿包含什么 |
|---|---|---|
| 角色与配队对照 | 查名称和 ID，按四星／五星筛选；补齐缺少的角色，对已有角色逐个或批量设置 0–6 命，支持撤销最近一次符合条件的变更 | 尚未收录完整控制器 |
| 武器 | 按筛选结果设精炼，支持可精炼四星武器一键满精；额外新增同一武器的多个副本，自选等级和精炼，不替换已有装备 | 尚未收录完整控制器 |
| 圣遗物 | 单件或同套五件生成；逐部位选主词条，按档位和次数配副词条，匹配目标值，保存和载入配方；标准预算和自由测试分开 | 双语主词条规划页；原版 C# 计算、校验源码和测试。网页不包含完整配方编辑或背包发放 |
| 战斗测试 | 使用服务端的木桩和 DPS 统计比较配装；对微粒数量／位置、充能、生命值同步、命座和天赋下发做过针对性修正 | 已收录特殊天赋分类代码示例；不是完整战斗引擎或修复合集 |
| 运行与存档 | 本机服务和数据库、固定版本、关键文件校验；退出客户端 30 秒后正常停服，再关数据库。联动退出有实际运行记录 | 已收录退出判定及测试；单独运行该模块不会启动或结束任何游戏进程 |

## 暂不支持、已知问题与未验证项

- **范围之外：** 剧情、任务推进和大世界探索不属于本项目支持范围。
- **逐角色战斗精度：** 有针对性修复和回归测试；燃素、命座额外攻击、队伍增益与最终伤害尚无逐项实机对照。木桩结果可用于本版本内对比，不作为官服伤害基准。关闭双水共鸣是本机测试配置，不是机制修复。
- **冷启动（已修复一处等待，待实机验收）：** 后台管理进程独立写日志，不再占用调用方的输出管道。[Windows 对照测试](runtime-tests/test_wait.py)用计时进程复现旧行为，验证修正后后台仍在运行而调用方已返回。一次真实冷启动中，服务端 14:33:46 就绪，游戏进程 14:33:49 启动，客户端随后进入登录流程；未据此验证窗口是否在前台或已进入世界。
- **版本和部署：** 没有适配 7.1 之后的客户端；全流程断网游玩、换盘或换机直接运行均未完成验收。本机安装使用固定路径。
- **英文覆盖：** README 和网页规划器已有英文。完整 Windows 角色、武器、圣遗物管理界面尚未全部英文化。
- **发行范围：** 当前代码不是整套本机环境的一键安装包。不含游戏客户端、美术资源、个人存档、账号、密钥或日志。
