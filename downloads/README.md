# Windows tool components / Windows 工具组件

[Download the checked Windows components / 下载已构建的组件](LOCAL-GI-ARENA-windows-tools-7.1.zip) · [SHA-256](LOCAL-GI-ARENA-windows-tools-7.1.zip.sha256)

Use the [assembly guide](../windows-local/distribution/README.md) for a new instance, and the [verification notes](../windows-local/distribution/ACCEPTANCE.md) before testing. The ZIP contains the Windows editor EXE, its compiled helper classes, two local server plugins, a separate class-only combat overlay and the corresponding controller source, combat patch, license and build instructions. No elevation required. An archive digest confirms transfer integrity, not publisher identity.

这是预编译组件，不是完整游戏或服务端安装器。单独的 combat-classes.jar 不是可直接运行的服务端。无需为组装脚本手动覆盖任何文件；它会自行编译工具。不要将这个 ZIP 解压覆盖现用环境。
