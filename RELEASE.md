# Windows portability preview / Windows 便携适配测试版

Includes a pinned server build recipe and source patch, local-instance assembler, Windows controller and server plugins, graphical control panel and health checks. [Binary components](downloads/) · [Setup](windows-local/distribution/README.md) · [Acceptance](windows-local/distribution/ACCEPTANCE.md)

本版提供构建、组装与服务端验收工具，不是可直接玩游戏的整包。完整服务端 JAR 仅在使用者私有目录构建。未包含游戏、外部资源、运行数据库、账号、证书或密钥。
