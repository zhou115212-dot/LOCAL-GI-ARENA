# LOCAL GI ARENA 0.1.0-preview.1

Windows / Genshin Impact 7.1 — Source & tools preview / 源码工具预览。

Extract the ZIP and open planner.html. Choose English or 中文, pick five main stats and export a worksheet. The built-in example requires no account, game data, installation or network. 解压后双击 planner.html。这是独立规划器，不向游戏发放装备。

Run the lifecycle tests with PowerShell and runtime-tests/test_wait.py with Python on Windows. The Java helper is an integration reference, not a standalone executable.

Not included: a complete combat server, full desktop controllers, game binaries or extracted game assets, accounts, databases, keys or private logs. 完整战斗环境、角色武器控制器以及游戏资源不在本次预览范围。
